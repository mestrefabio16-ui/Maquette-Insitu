# Livret In Situ — maquette feuilletable

Maquette du livret A5 de 4 pages « Atelier bois In Situ », aux couleurs de 3B Emballages.
**Il s'agit d'une maquette : les textes, les chiffres et les visuels sont fictifs.**

## Mettre en ligne avec GitHub Pages (sans ligne de commande)

1. Sur github.com, cliquez sur **New repository**, nommez le dépôt (par exemple `livret-insitu`), cochez **Public**, puis cliquez sur **Create repository**.
2. Sur la page du dépôt, cliquez sur **uploading an existing file**.
3. Glissez **tout le contenu de ce dossier** (`index.html`, le dossier `pages`, `apercu.jpg`, `livret-maquette.pdf`, `README.md`), puis cliquez sur **Commit changes**.
4. Allez dans **Settings → Pages**. Sous *Branch*, choisissez **main** et **/ (root)**, puis cliquez sur **Save**.
5. Après une à deux minutes, le lien s'affiche en haut de cette page :
   `https://VOTRE-PSEUDO.github.io/livret-insitu/`

C'est ce lien que vous envoyez. Le livret s'ouvre directement et se feuillette d'un clic, avec les flèches du clavier ou en balayant sur téléphone.

## Contenu

| Fichier | Rôle |
|---|---|
| `index.html` | Le livret feuilletable |
| `pages/page-1.jpg` … `page-4.jpg` | Les 4 pages du livret |
| `livret-maquette.pdf` | Le PDF A5, téléchargeable depuis la page |
| `apercu.jpg` | Le mock-up, utilisé comme image d'aperçu quand on partage le lien |

Pour mettre à jour le livret, remplacez les images dans `pages/` en gardant les mêmes noms de fichiers.
